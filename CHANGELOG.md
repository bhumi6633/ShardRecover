# Changelog

## v0.1.0

- Added deterministic binary fragmentation and controlled damage simulation.
- Added exact and bounded-mismatch overlap graphs with exhaustive, indexed, and parallel construction.
- Added greedy and beam-search reconstruction with consensus and optional PNG CRC-guided repair evidence.
- Added PNG structure, semantic, and CRC analysis.
- Added buffered and memory-mapped fragment loading.
- Added native tests, sanitizer support, bounded fuzz targets, graph benchmarks, and recovery evaluation.
- Added schema-v1 JSON reconstruction traces.
- Added the React/TypeScript forensic graph workstation with mismatch, repair, timeline, and PNG evidence panels.
